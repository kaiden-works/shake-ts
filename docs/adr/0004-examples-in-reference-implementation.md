# 0004: 例を参照実装のリポジトリーに置く

## ステータス

有効

## 背景

仕様の例は仕様のリポジトリーにあり、仕様のリポジトリーの CLI がスキーマへの適合と、検証手順のうち文書だけで確かめられる項目を検査している。この検査は[発行前チェック CLI](../PRD.md#発行前チェック-cli) の責務と同じで、2 つのリポジトリーで同じ検査を管理している。

仕様のリポジトリーは規範を置く場所である。例とその生成、検査は仕様に付随するもので、規範ではない。例をどちらのリポジトリーに置くかを決める必要がある。

## 選択肢

### 選択肢 A: 仕様のリポジトリーに置く

例とその生成、検査の CLI を仕様のリポジトリーに置く。

利点は、仕様の改訂と例の修正を 1 つのコミットで行えることである。

欠点は次のとおり。

- 文書の検査を仕様のリポジトリーと参照実装で二重に管理する
- 規範でないものが規範の置き場に混ざる

### 選択肢 B: 参照実装のリポジトリーに置く

例を本リポジトリーの `examples/` に置き、生成と検査は参照実装の CLI で行う。

利点は次のとおり。

- 文書の検査が参照実装の 1 箇所に決まる
- 仕様のリポジトリーが規範だけを持つ

欠点は、仕様の改訂で例を直すとき、2 つのリポジトリーにまたがることである。

## 決定

選択肢 B を採用する。

例の検査は発行前チェック CLI と同じ責務であり、1 箇所にまとめる。仕様のリポジトリーには規範だけを残す。

### 選定に影響しなかった点

特になし。

## トレードオフ

仕様の改訂が例に影響するとき、仕様のリポジトリーと本リポジトリーを順に直す。
