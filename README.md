# shake-ts

kaiden shake 到達クレデンシャル仕様の参照実装。

## 仕様との関係

規範は仕様の文書であり、本リポジトリーの実装ではない。実装と仕様が食い違う場合、仕様を正とし、実装を直す。

参照実装は次の 4 つからなる。

- 検証者が VC を検証する CLI
- 評価者と保証者が自分の文書と VC ペイロードを発行前に検査する CLI
- VC を発行する CLI
- 保持者の提示を作る CLI

仕様の例は [examples/](examples/) に置く。

ウォレット、発行サーバー、検証サーバーなどの製品級の実装は含まない。npm などのパッケージとしては配布しない。リポジトリーを checkout して実行する。

## 開発

Node.js 24 で TypeScript を直接実行する。

```sh
pnpm install
pnpm test
```
